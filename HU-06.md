# HU-06: Eliminar o cancelar una campaña

El creador gestiona el retiro de sus campañas desde la vista de resumen.

- Un borrador sin aportes muestra la opción **Eliminar campaña**.
- Antes del borrado se presenta una confirmación explícita que advierte que la acción es permanente.
- Al confirmar, el registro y su imagen se eliminan físicamente de SQLite y la interfaz regresa a **Mis campañas**.
- Un borrador con aportes no puede eliminarse, aunque se intente llamar directamente a la API.
- Una campaña activa muestra el botón con el texto exacto **Cancelar Campaña**.
- Antes de cancelar se solicita una confirmación explícita y se informa que la campaña dejará de ser pública y no recibirá aportes.
- Al cancelar, el estado cambia a `Cancelada`; la campaña deja de aparecer en el catálogo público y ya no es accesible por otros usuarios.
- La campaña cancelada permanece en **Mis campañas** como registro del creador.
- Solo el propietario autenticado puede ejecutar ambas acciones y las solicitudes validan su origen.

## API

- `DELETE /api/campaigns/:id`: elimina un borrador propio cuyo monto recaudado sea cero.
- `POST /api/campaigns/:id/cancel`: cambia una campaña propia de `Activa` a `Cancelada`.

La base de datos se migra automáticamente para admitir el estado `Cancelada` sin perder campañas existentes.

## Verificación

`bun test` comprueba el borrado físico, las restricciones por estado y aportes, permisos, protección de origen, cancelación, visibilidad pública y migración.

`bun run build` compila la interfaz Vue.
