# HU-01: Crear una nueva campaña

Rama: feature/Crear_Campañas.

Desde la homepage, "Crear campaña" abre /#/campaigns/new.
Todos los campos son obligatorios: título, descripción, categoría, imagen,
meta de financiamiento en CLP y fecha límite.

- Los campos vacíos muestran "Campo requerido" junto al campo y bloquean el envío.
- La meta debe ser un número mayor a 0; admite coma o punto decimal (hasta 2 decimales), sin separadores de miles.
- La fecha límite debe ser posterior al día actual en America/Santiago.
- Se admiten imágenes JPG, PNG o WebP de hasta 5 MB.
- Título: hasta 120 caracteres. Descripción: hasta 10.000 caracteres.
- El servidor valida nuevamente todos los campos antes de insertar.
- SQLite guarda imagen y datos, asocia al usuario autenticado y asigna "Borrador".
- Un identificador de solicitud evita duplicados al reintentar un guardado.
- Tras guardar se abre /#/campaigns/:id con los datos y la etiqueta Borrador.
- Mis campañas permite regresar a los resúmenes; cada usuario solo accede a sus campañas.
- El botón "Activar campaña" cambia Borrador a Activa. Solo el creador puede activarla.

## API

POST /api/campaigns recibe multipart/form-data con los seis campos y creationKey.
Los errores de validación devuelven 422 y un objeto errors por campo.
GET /api/campaigns lista las campañas del usuario.
GET /api/campaigns/:id devuelve su resumen.
GET /api/campaigns/:id/image devuelve su imagen.
POST /api/campaigns/:id/activate activa la campaña del usuario.
Todos requieren sesión; el POST además valida Origin.

## Ejecución y verificación

Usar bun run dev:server y bun run dev en terminales separadas.
La tabla campaigns se crea automáticamente al arrancar el servidor actualizado,
sin eliminar usuarios o sesiones existentes. Si el servidor se inició sin --watch, reiniciarlo.

bun test ejecuta los criterios de aceptación, permisos, reintentos y persistencia.
bun run build verifica la compilación de Vue.
