# HU-07: Aportar a una campaña

Una persona autenticada puede simular un aporte económico desde el detalle de una campaña activa.

- El botón **Aportar** despliega un formulario con el monto en CLP y **Confirmar aporte**.
- El monto debe ser un número entero de CLP mayor a cero; los aportes con decimales se rechazan.
- Al confirmar, el formulario se bloquea y muestra una ruedita junto al texto **Confirmando pago…** durante 5 segundos.
- Solo después de finalizar la espera se muestra **Pago exitoso**.
- El aporte se registra en SQLite y se suma de manera transaccional al monto recaudado de la campaña.
- La vista actualiza el total recaudado, el porcentaje financiado y la barra de progreso.
- Cualquier usuario autenticado, incluido el creador, puede aportar.
- Los borradores y las campañas canceladas rechazan aportes desde la interfaz y desde la API.
- Esta funcionalidad es una simulación y no se conecta con un medio de pago real.

## API

`POST /api/campaigns/:id/contributions` recibe JSON con `amount` y devuelve el aporte registrado junto con la campaña actualizada.

Los aportes se almacenan en la tabla `contributions`. La inserción y el incremento de `raised_cents` se ejecutan en una sola transacción.

## Verificación

`bun test` comprueba acumulación matemática, persistencia, permisos, validación de montos y bloqueo por estado.

`bun run build` compila la interfaz Vue.
