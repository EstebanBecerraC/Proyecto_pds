# HU-08: Ver historial de aportes (Listar Aportes)

Como usuario de la plataforma, quiero ver una lista de las personas que han aportado a una campaña para comprobar que el proyecto es real y ver el respaldo de la comunidad (Principio de Confianza).

## Comportamiento

- La vista de detalle incluye **Historial de aportes**, después de la descripción del proyecto.
- Cada transacción se muestra por separado con nombre del aportante y monto en CLP: **Juan aportó $10.000**.
- Se incluyen todos los aportes de esa campaña, del más reciente al más antiguo, con un orden estable por identificador.
- Si una persona aporta varias veces, cada aporte aparece en su propia línea.
- Una campaña activa sin aportes muestra: **Esta campaña aún no tiene aportes. ¡Sé la primera persona en aportar!**
- En borradores o canceladas propias sin aportes, el mensaje informa que no existen aportes y no invita a donar.
- Después de confirmar un aporte mediante HU-07, el historial se vuelve a consultar y muestra la nueva transacción sin recargar la página.
- La carga tiene un indicador propio. Si falla, aparece un error y **Reintentar historial**, sin presentar el fallo como una campaña sin aportes ni ocultar el resto del detalle.
- Las respuestas anteriores se descartan al cambiar de campaña o iniciar una consulta más reciente, para evitar mezclar historiales.

## API y permisos

`GET /api/campaigns/:id/contributions` devuelve:

```json
{
  "contributions": [
    {
      "id": 1,
      "contributor_name": "Juan",
      "amount_cents": 1000000,
      "created_at": "2026-10-09 01:00:00"
    }
  ]
}
```

- Una campaña existente sin aportes devuelve 200 y `contributions: []`.
- El nombre se obtiene de la cuenta del aportante. El monto y la fecha proceden de la transacción almacenada.
- Se requiere sesión. Las campañas activas son visibles para todos los usuarios autenticados; los borradores y las canceladas conservan acceso exclusivo para su creador.
- Una campaña inexistente o no visible para el usuario devuelve 404. Una sesión ausente o vencida devuelve 401.
- No se exponen correos, contraseñas ni identificadores de usuario del aportante.
- Se utiliza la tabla `contributions` existente de HU-07, incluyendo sus aportes anteriores. No se modifica el esquema ni se agregan dependencias.
- `POST /api/campaigns/:id/contributions` mantiene el flujo de donación existente.

## Revisión manual

1. Abrir una campaña activa que ya tenga aportes y desplazarse hasta **Historial de aportes**. Comprobar cada nombre y monto.
2. Abrir una campaña activa sin aportes. Comprobar el mensaje que invita a aportar.
3. Confirmar un aporte. Comprobar que el historial cambia automáticamente y muestra una sola línea nueva con nombre y monto.
4. Recargar y verificar que los aportes permanecen. Donar otra vez y comprobar que hay otra transacción separada.
5. Cambiar a otra campaña y comprobar que solo se muestran sus aportes.
