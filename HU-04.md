# HU-04: Buscar campañas

La vista principal permite buscar campañas activas por una coincidencia parcial en el título o la descripción.

- La búsqueda se ejecuta al presionar Enter o seleccionar el botón Buscar.
- Las coincidencias no distinguen entre mayúsculas y minúsculas.
- Solo se incluyen campañas activas.
- Los resultados conservan la paginación de 25 campañas y el término se mantiene al cambiar de página.
- Una búsqueda sin coincidencias muestra: "No se encontraron campañas para esta búsqueda".
- Limpiar la búsqueda restaura el catálogo completo.
- El término admite hasta 120 caracteres. Los símbolos `%`, `_` y `\\` se buscan como texto literal.

## API

`GET /api/campaigns/catalog?page=1&q=termino` devuelve las campañas cuyo título o descripción contienen el término, junto con la paginación correspondiente.

Los espacios exteriores se ignoran. Si `q` está vacío o contiene solo espacios, se devuelve el catálogo completo.

## Verificación

`bun test` comprueba coincidencias en título y descripción, ausencia de resultados, paginación, estados, caracteres especiales y validación.

`bun run build` compila la interfaz Vue.
