# HU-09: Gestionar perfil de usuario

**Como** persona usuaria autenticada, **quiero** consultar y administrar mi perfil, **para** mantener mis datos actualizados y controlar mi cuenta.

## Criterios de aceptación

1. Al abrir **Mi perfil**, se muestran el nombre y correo de la cuenta autenticada.
2. Se pueden modificar nombre y correo. Los cambios válidos persisten y se confirma el guardado.
3. El nombre, una vez recortados los espacios exteriores, debe tener entre 2 y 80 caracteres. El correo debe cumplir las reglas del registro y no pertenecer a otra cuenta.
4. Para cambiar la contraseña, se exige la actual, una nueva de 8 a 128 caracteres y su confirmación coincidente. Si los tres campos quedan vacíos, la contraseña se conserva.
5. Una validación fallida informa el error y no guarda cambios parciales.
6. Eliminar una cuenta exige confirmar escribiendo exactamente `entiendo`.
7. No se permite eliminar una cuenta mientras tenga campañas activas creadas por ella.
8. Al eliminar, se anonimizan sus datos, se invalidan sus sesiones y se conservan los aportes existentes.
9. La página y API requieren sesión. Cada cuenta solo puede operar sobre su propio perfil.

## Ubicación e implementación

- Interfaz: [ProfilePage.vue](src/components/ProfilePage.vue), ruta `#/profile`.
- API: [profile.js](server/profile.js).
- Validaciones: [shared/profile.js](shared/profile.js).
- Integración de sesión y rutas: [App.vue](src/App.vue) y [auth.js](server/auth.js).

Las contraseñas se almacenan como hashes Argon2id. La eliminación es lógica: marca `deleted_at`, reemplaza los datos personales y borra las sesiones. No elimina físicamente las filas relacionadas con aportes.

## API

Todas las operaciones actúan sobre el usuario de la sesión; PUT y DELETE validan el origen.

| Operación | Comportamiento |
|---|---|
| GET /api/profile | Devuelve `profile` con id, nombre, correo y fecha de creación. |
| PUT /api/profile | Actualiza nombre y correo; cambia contraseña cuando se proporcionan los campos correspondientes. |
| DELETE /api/profile | Recibe `{ "confirmation": "entiendo" }`; devuelve 204 y expira la cookie si se permite eliminar. |

Las validaciones devuelven 422; un correo ocupado o una eliminación bloqueada por campañas activas devuelve 409. La ausencia de sesión devuelve 401.
